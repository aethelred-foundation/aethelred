# M42 × Aethelred — AI Compute Assurance Pilot
### Auditable cost, energy, and execution provenance for sovereign healthcare AI

---

M42 is scaling advanced AI across clinical, genomic, research, and digital‑health environments. As those workloads grow, M42 needs an independently verifiable way to know **where an approved workload ran, which model and software executed, what it cost, and how much energy was attributable to it — without moving sensitive data outside M42's control.**

Aethelred deploys **inside an M42‑controlled environment** and produces a tamper‑evident evidence record for each approved execution. The result is an assurance layer *around* your existing AI workflows — not a competing clinical model.

---

## What Aethelred proves for a given AI workload

| Question M42 can answer | How |
|---|---|
| **Where did it run?** | Hardware attestation binds execution to an approved, measured environment |
| **Which model & software?** | Model‑identity and container/measurement commitments in the evidence record |
| **What did it cost?** | Unit cost reproducible from M42‑approved input rates |
| **How much energy?** | Job‑attributable compute energy within an agreed measurement boundary |
| **Did data stay in‑boundary?** | No raw patient data, model weights, or identifiable input leaves M42's environment |

Each record is **independently verifiable by an M42 engineer using a standalone tool** — no dependency on an Aethelred hosted service.

```
approved workload → approved environment → approved model
        → measured compute → measured energy → known cost
        → independently verifiable evidence record → M42 verifier / dashboard
```

## Why this fits M42's priorities

Aethelred's proposition maps directly to M42's public strategy — real‑world AI deployment, sovereign and governed data use, sustainability and transparent ESG reporting, ethical AI, and accountable partnerships. Cryptography, attestation, and post‑quantum signatures are *supporting mechanisms*, not the sales proposition.

## The pilot

A **fixed‑fee, phase‑gated, 10–12 week** engagement inside an M42‑controlled environment covering:

- **One initial low‑risk / non‑patient workload** (fast technical gate).
- **One real‑world shadow‑mode workload** (flagship operational validation, no effect on clinical decisions).
- **One live hardware attestation path** on production vendor collateral.
- **One agreed energy‑measurement boundary**, reconciled to a ground‑truth instrument.
- **A standalone, M42‑operated verifier.**
- **A production scale‑up business case** built on M42's own baseline metrics.

**Phase gates limit M42's delivery risk:** if Aethelred cannot operate in the approved environment or generate independently verifiable evidence at the deployment gate, M42 can stop before later milestones. (Full phase table, deliverables, responsibilities, acceptance criteria, and pricing in the accompanying **Pilot SOW**.)

## What M42 receives — even without proceeding to production

An independently operable verifier, a verified workload baseline, an attestation‑and‑measurement report, optimization findings, a security & governance pack (including DPIA support), and a production scale‑up business case.
