# Aethelred Private Bug Bounty Invitation Template

Subject: Invitation: Aethelred Private Protocol Bug Bounty

Hello {{researcher_name}},

We are inviting a small group of researchers to participate in the private Aethelred protocol bug bounty.

Aethelred is currently operating a protocol-first security program focused on the core chain, validator/node surfaces, RPC/API/gRPC endpoints, release artifacts, and other security-critical protocol components. This phase is private and invitation-only while we complete testnet hardening and prepare for mainnet security closure.

Scope summary:
- Core Aethelred protocol and node software
- Validator and operator-critical workflows
- RPC, REST API, gRPC, and other protocol-facing interfaces
- Release artifacts and supply-chain relevant protocol surfaces
- Other assets explicitly listed in the program documentation

Out of scope for this phase:
- Standalone dApps
- Social engineering, spam, phishing, or physical attacks
- Third-party services outside Aethelred control
- Issues that require unrealistic assumptions or non-actionable reports

Program documents:
- `SECURITY.md`
- `docs/security/BUG_BOUNTY_PROGRAM.md`
- `docs/security/BUG_BOUNTY_SEVERITY_MATRIX.md`
- `docs/security/BUG_BOUNTY_SLA.md`

Rewards:
- Rewards are assessed in USD value and normally paid in USDC
- Final reward decisions are based on severity, exploitability, impact, and report quality

Submission channel:
- `security@aethelred.io`

Please include:
- affected asset or component
- concise impact statement
- reproduction steps
- proof of concept, logs, or code where relevant
- suggested remediation if you have one

This program is covered by the Aethelred coordinated disclosure and safe harbor policy as described in `SECURITY.md`.

If you would like to participate, reply to confirm:
- your preferred contact address
- your preferred payout rail
- any conflicts or scope restrictions you want us to note
